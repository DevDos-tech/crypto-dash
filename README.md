# 📊 Crypto Dash

Dashboard de criptomoedas construído com **React** e **Vite**, criado para acompanhar preços, variações e dados de mercado das principais criptomoedas em tempo real.

> 🚧 Projeto em desenvolvimento ativo. Novas funcionalidades sendo adicionadas continuamente.

---

## ✨ Funcionalidades

- 📈 Visualização de preços e variações de criptomoedas
- 🔍 Navegação entre páginas com React Router
- ⚡ Build rápido e hot-reload com Vite
- 🎨 Interface responsiva
---

## 🚀 Como rodar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado (versão 18+ recomendada)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/DevDos-tech/crypto-dash.git

# Entre na pasta do projeto
cd crypto-dash

# Instale as dependências
npm install
```

### Executando em desenvolvimento

```bash
npm run dev
```

### Build para produção

```bash
npm run build
```
